### Sobre

A seguinte coleção de scripts foram desenvolvidos para simplificar tarefas recorrentes, facilitar a administração de sistemas e fornecer informações úteis sobre os recursos do computador.

O repositório reúne ferramentas voltadas para monitoramento de recursos computacionais, gerenciamento de arquivos, análise de conexões de rede e configuração de interfaces de rede. A proposta é reduzir etapas manuais, tornar procedimentos técnicos mais acessíveis e agilizar operações realizadas frequentemente no dia a dia.

Para isso, os scripts combinam recursos nativos dos sistemas operacionais com comandos e funcionalidades específicas, utilizando interfaces de linha de comando para oferecer fluxos de execução simples e objetivos.

O projeto também serve como um espaço de experimentação e aprendizado em automação de tarefas, administração de sistemas e desenvolvimento de scripts para diferentes ambientes.

### Objetivos

- **Automação:** simplificar tarefas repetitivas e reduzir a necessidade de executar manualmente sequências extensas de comandos.
- **Monitoramento:** facilitar a consulta de informações sobre recursos computacionais e conexões de rede.
- **Administração de sistemas:** tornar determinadas configurações e operações mais rápidas e acessíveis.
- **Praticidade:** reunir ferramentas independentes que podem ser utilizadas conforme a necessidade.
- **Aprendizado:** explorar recursos de shell scripting, automação e gerenciamento de sistemas operacionais.

### O que usamos

| Stack | Aplicação |
| --- | --- |
| Bash / Shell Script | Automação de tarefas em ambientes Linux e shells compatíveis. |
| PowerShell | Consulta de informações do sistema e gerenciamento de recursos no Windows. |
| Batch (.bat) | Automação de comandos e configuração de recursos no Windows. |

## Scripts disponíveis

### Bash / Shell

**[Movendo arquivos](https://github.com/glermFF/Scripts/blob/main/bash/transfer_files.sh)**

Script voltado à transferência de arquivos por meio do terminal, auxiliando na execução de operações com arquivos e tornando esse processo mais prático.

### PowerShell

**[Recursos da CPU](https://github.com/glermFF/Scripts/blob/main/powershell/cpu_resources.ps1)**

Permite consultar informações relacionadas aos recursos da CPU e aos processos em execução. Pode auxiliar na identificação de consumo elevado de recursos, na investigação inicial de possíveis gargalos e na compreensão das atividades realizadas pelo sistema.

**[Portas e conexões de rede](https://github.com/glermFF/Scripts/blob/main/powershell/pc_connections.ps1)**

Apresenta informações sobre conexões de rede e comunicações associadas ao computador. É uma ferramenta auxiliar para observar conexões ativas, compreender melhor as atividades de rede e realizar verificações preliminares durante tarefas de diagnóstico ou auditoria.

### Batch (.bat)

**[Configurar interfaces de rede](https://github.com/glermFF/Scripts/blob/main/bat/IP)**

Reúne comandos destinados à configuração de interfaces de rede no Windows, incluindo operações relacionadas ao endereçamento IP e à ativação ou desativação de interfaces.

A proposta é simplificar tarefas de configuração por meio de um fluxo de execução interativo, reduzindo a quantidade de etapas manuais necessárias para realizar operações comuns de gerenciamento de rede.

## Teste você também

### 1. Escolha o script

Navegue até o diretório correspondente e selecione a ferramenta que deseja utilizar. Cada script possui uma finalidade específica e deve ser executado em um ambiente compatível com a tecnologia utilizada.

### 2. Execute no ambiente apropriado

- **Bash:** utilize um terminal com suporte ao Bash.
- **PowerShell:** execute o script em um ambiente PowerShell compatível.
- **Batch:** utilize o Prompt de Comando do Windows.

Consulte o conteúdo de cada arquivo antes da execução para compreender os comandos realizados e os parâmetros eventualmente necessários.

## Requisitos e observações

- O sistema operacional e o interpretador utilizados devem ser compatíveis com o script escolhido.
- Alguns procedimentos de configuração e gerenciamento podem exigir privilégios administrativos.
- A disponibilidade de comandos e recursos pode variar conforme a versão do sistema operacional e o ambiente de execução.
- Os scripts devem ser revisados antes de serem executados, especialmente quando alteram configurações do sistema ou interfaces de rede.

## Contribuições

Sugestões, correções e novas implementações são bem-vindas. Contribuições que melhorem a funcionalidade, a legibilidade, a compatibilidade ou a documentação dos scripts podem ajudar a tornar o repositório mais útil.

Ao propor alterações, procure manter os scripts organizados, documentar seu propósito e informar eventuais requisitos específicos de execução.
